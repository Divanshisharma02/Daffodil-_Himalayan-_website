# Daffodil Himalayan - Mobile Application Architecture (iOS & Android)

## Overview
Design specification for the native/cross-platform mobile app matching **Daffodil Himalayan** website luxury aesthetics.

### Color Palette
- Deep Forest Green: `#0B3D2E`
- Midnight Blue: `#0B1F3A`
- Gold Accent: `#D4AF37`
- Background: `#FBF9F5`

### Screen Architecture (React Native / Flutter)
1. **Splash Screen**: Animated gold emblem and registration badge (`11-2279/2024-DTO-SML`).
2. **Auth Screen**: Biometric FaceID / Fingerprint & JWT login.
3. **Home Dashboard**: Native video hero carousel, Pill search bar.
4. **Interactive Itinerary Screen**: Animated SVG node flow chart with offline caching.
5. **PDF Invoice Viewer**: Instant native PDF preview & download for completed bookings.
